# REST API

Interactive OpenAPI docs: **http://localhost:8000/docs** (generated by FastAPI).

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/health` | Status of Postgres, Redis and the rules service (`ok` / `degraded`) |
| `POST` | `/claims` | Validate a `ClaimEvent` and publish it to the stream → `202 Accepted` |
| `GET` | `/claims/{claim_id}` | A claim with its score, the rules that fired, and policy context |
| `POST` | `/score` | **What-if**: score a claim synchronously without saving it |
| `GET` | `/alerts?limit=50` | Most recent HIGH-risk claims (live from Redis, falling back to Postgres) |
| `GET` | `/metrics/live?minutes=60` | Per-minute throughput, amount, high-risk count, latency p50/p95, consumer lag |
| `GET` | `/kpis/daily?days=120` | Daily claims, cost, average amount, fraud rate (historical book) |
| `GET` | `/regions` | Region league table (share of cost, rank, high-risk rate) |
| `GET` | `/forecast` | 30-day forecasts (SARIMA and LSTM, with intervals) plus the back-test series |
| `GET` | `/models` | Model metrics, live risk mix, score histogram, feature importance |

## Example

```bash
curl -s -X POST localhost:8000/score -H 'content-type: application/json' -d '{
  "claim_id": "CLM-demo-0001", "policy_id": 1,
  "loss_ts": "2026-10-12T10:00:00Z", "reported_ts": "2026-10-14T02:30:00Z",
  "amount": 18000, "claim_type": "theft", "channel": "web"
}'
```
```json
{"claim_id":"CLM-demo-0001","model_score":0.697,"rule_score":35,
 "rules_hit":["HIGH_AMOUNT_FOR_REGION","NIGHT_WEB_SUBMISSION"],
 "risk_level":"HIGH","model_version":"fraud-lgbm-…","region":"Rhone-Alpes","latency_ms":13.3}
```

## ClaimEvent contract (v1)

| Field | Type | Rules |
|---|---|---|
| `schema_version` | int | `1` |
| `claim_id` | string | 8–64 characters, unique |
| `policy_id` | int | > 0, must exist |
| `loss_ts`, `reported_ts` | ISO-8601 datetime | timezone-aware; `reported_ts ≥ loss_ts` |
| `amount` | float | 0 < amount < 5,000,000 |
| `claim_type` | enum | `collision`, `theft`, `glass`, `liability`, `fire` |
| `channel` | enum | `web`, `app`, `phone`, `agent` |
| `fraud_label` | bool, optional | simulator ground truth only |
